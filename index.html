Controls

Playback

  • SPACE - Start/Stop

  • 0 - Return to start

Functions

  • RESET - Reset all parameters
  • MUTE - Toggle audio mute
  • RECORD - Record & save your realtime audio
  • LOOP - Scrolls playhead through entire waveform
  • WARP - Locks in a high frequency micro-loop
